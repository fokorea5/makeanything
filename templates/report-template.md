# 제작자 보고 양식 (Report Template)

모든 보고는 반드시 아래 양식을 따릅니다.
보고를 받는 사람은 제작자(정찬)이므로, **쉬운 말**로 작성합니다.

---

## 기본 보고 양식

```
═══════════════════════════════════════════
📋 제작자 보고서
═══════════════════════════════════════════

▶ 현재 단계: [예: 2단계 - 설계]
▶ 담당 에이전트: [예: 기술 아키텍트, 인터페이스 디자이너]

───────────────────────────────────────────
📌 진행 내용 요약
───────────────────────────────────────────
- [완료한 작업 1]
- [완료한 작업 2]
- [완료한 작업 3]

───────────────────────────────────────────
🔍 의사결정이 필요한 사항
───────────────────────────────────────────
결정 사항: [무엇을 결정해야 하는지]

  선택지 A: [이름]
    - 좋은 점: ...
    - 드는 비용: ...
    - 위험한 점: ...

  선택지 B: [이름]
    - 좋은 점: ...
    - 드는 비용: ...
    - 위험한 점: ...

  팀 추천: [A 또는 B], 이유: [한 줄]

───────────────────────────────────────────
💰 예상 비용 / 리스크
───────────────────────────────────────────
- 예상 비용: [금액 또는 시간]
- 주요 리스크: [있으면 기재, 없으면 "없음"]
- 대응 방안: [리스크가 있을 경우]

───────────────────────────────────────────
⏳ 제작자 승인 대기 중
───────────────────────────────────────────
위 내용을 검토하시고, 다음 중 하나를 선택해 주세요:
  1. ✅ 승인 - 다음 단계로 진행
  2. 🔄 수정 요청 - [수정할 내용을 말씀해 주세요]
  3. ❓ 질문 - [궁금한 점을 물어봐 주세요]

═══════════════════════════════════════════
```

## 긴급 보고 양식

문제가 발생했을 때 사용합니다.

```
═══════════════════════════════════════════
🚨 긴급 보고서
═══════════════════════════════════════════

▶ 보고 에이전트: [에이전트 이름]
▶ 긴급도: [높음 / 중간 / 낮음]

───────────────────────────────────────────
⚠️ 문제 상황
───────────────────────────────────────────
- 무슨 일이 생겼나: [쉬운 말로 설명]
- 영향 범위: [어디에 영향을 미치는지]

───────────────────────────────────────────
🔧 대응 방안
───────────────────────────────────────────
  방안 A: [설명]
    - 걸리는 시간: ...
    - 비용: ...

  방안 B: [설명]
    - 걸리는 시간: ...
    - 비용: ...

  팀 추천: [A 또는 B], 이유: [한 줄]

═══════════════════════════════════════════
```

## 의도 매칭 검수 보고 양식

개발 완료 후 의도 매칭 분석가가 사용합니다.

```
═══════════════════════════════════════════
🔍 의도 매칭 검수 보고서
═══════════════════════════════════════════

▶ 검수 일시: [날짜]
▶ 검수 대상: [기능 또는 전체]

───────────────────────────────────────────
📊 요구사항 매칭 결과
───────────────────────────────────────────

번호 | 최초 요구사항         | 구현 상태 | 매칭
-----|---------------------|-----------|---------
 1   | [요구사항 내용]       | 완료/미완  | ✅/⚠️
 2   | [요구사항 내용]       | 완료/미완  | ✅/⚠️
 3   | [요구사항 내용]       | 완료/미완  | ✅/⚠️

매칭률: [OO%]

───────────────────────────────────────────
⚠️ 누락 사항 (있는 경우)
───────────────────────────────────────────
- [누락된 요구사항]: [조치 계획]

───────────────────────────────────────────
📝 범위 변경 사항
───────────────────────────────────────────
- 없음 / [변경 내역]

═══════════════════════════════════════════
```
