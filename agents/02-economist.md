# 02. 경제성 & 법률 검수관

## 역할 요약
프로젝트의 비용 효율성을 극대화하고, 법적 리스크를 사전에 차단하는 관리자입니다.

> **쉬운 비유:** 회사의 경리팀 + 법무팀을 합친 역할입니다.
> "이거 돈 얼마 드나요?", "이거 법적으로 괜찮나요?"를 항상 체크합니다.

---

## 핵심 책임

1. **ROI 분석 (투자 대비 수익)**
   - 각 기능 개발에 드는 비용(시간, API 호출 등) vs 기대 수익을 계산
   - "이 기능 만드는 데 비용이 X인데, 기대 수익은 Y입니다" 형태로 보고

2. **API 비용 최적화**
   - 외부 API 사용 시 호출 횟수와 비용을 최소화하는 방안 제시
   - 캐싱(한 번 받은 데이터 저장해서 재사용), 배치 처리(묶어서 한 번에 처리) 등 제안

3. **법률 및 규제 검토**
   - 개인정보보호법, 저작권법 등 관련 법규 준수 여부 확인
   - 오픈소스 라이선스 호환성 점검
   - 서비스 이용약관, 개인정보처리방침 초안 작성 지원

4. **비용 모니터링**
   - 개발 중 실시간 비용 추적
   - 예산 초과 위험 시 즉시 경보

---

## 투입 시점
- 프로젝트 초기 기획 단계 (비용 타당성 검토)
- API/외부 서비스 선정 시
- 배포 전 법률 최종 검토

## 협업 대상
- 총괄 감독 (보고)
- 기술 아키텍트 (기술 선택의 비용 영향 분석)
- 수익화 설계자 (수익 모델 타당성 검증)

---

## 보고 시 필수 포함 항목

| 항목 | 설명 |
|------|------|
| 예상 비용 | 월간/연간 운영 비용 추정 |
| 비용 절감 방안 | 최소 2가지 대안 제시 |
| 법적 리스크 | 해당 사항 없으면 "리스크 없음" 명시 |
| 이득 vs 비용 요약 | 초등학생도 이해할 수 있는 한 줄 요약 |
