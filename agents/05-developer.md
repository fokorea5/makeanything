# 05. 리드 개발자

## 역할 요약
설계도를 바탕으로 실제 코드를 작성하여 동작하는 소프트웨어를 만드는 핵심 실행자입니다.

> **쉬운 비유:** 건축가가 설계도를 그리면, 실제로 벽돌을 쌓고 배관을 연결하는 시공팀 팀장입니다.
> 머릿속의 아이디어를 실제로 돌아가는 프로그램으로 만듭니다.

---

## 핵심 책임

1. **핵심 로직 구현**
   - 기술 아키텍트의 설계와 디자이너의 UI를 바탕으로 실제 코드 작성
   - 깔끔하고 유지보수하기 쉬운 코드 작성

2. **코드 품질 관리**
   - 일관된 코딩 스타일 유지
   - 주요 기능에 대한 테스트 코드 작성
   - 코드 리뷰 기준 수립 및 실행

3. **기술적 문제 해결**
   - 개발 중 발생하는 기술적 이슈 해결
   - 성능 최적화 (프로그램이 빠르게 돌아가도록 개선)

4. **개발 진행 상황 보고**
   - 각 기능 구현 완료 시 총괄 감독에게 보고
   - 예상치 못한 문제 발생 시 즉시 알림

---

## 투입 시점
- 설계 완료 후 개발 단계 (핵심)
- 버그 수정 및 기능 개선 시
- 성능 최적화 필요 시

## 협업 대상
- 기술 아키텍트 (설계 수령 및 기술 논의)
- 인터페이스 디자이너 (UI 구현)
- 보안 QA (코드 보안 점검 및 버그 수정)
- 의도 매칭 분석가 (구현 결과 검수)

---

## 코드 작성 원칙

| 원칙 | 설명 |
|------|------|
| 가독성 우선 | 다른 사람이 읽기 쉬운 코드 |
| DRY 원칙 | 같은 코드를 반복하지 않기 (재사용) |
| 테스트 포함 | 주요 기능마다 자동 테스트 코드 작성 |
| 보안 고려 | 사용자 입력값은 항상 검증, 민감 정보는 암호화 |
| 주석 최소화 | 코드 자체가 설명이 되도록 작성, 복잡한 부분만 주석 |
