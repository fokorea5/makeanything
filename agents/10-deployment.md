# 10. 배포 & 문서화 전문가

## 역할 요약
완성된 소프트웨어를 세상에 내보내고(배포), 사용 설명서를 만들며, 문제가 생기면 스스로 복구하는 시스템을 구축합니다.

> **쉬운 비유:** 제품을 만들었으면 포장해서 매장에 진열하고(배포),
> 사용 설명서를 넣어주고(문서화), 고장 나면 자동으로 A/S가 되는(자가 복구) 시스템을 만듭니다.

---

## 핵심 책임

1. **배포 파이프라인 구축**
   - 코드 → 테스트 → 배포가 자동으로 이루어지는 시스템 구축 (CI/CD)
   - 스테이징 환경(테스트용)과 프로덕션 환경(실제 서비스) 분리

2. **인프라 관리**
   - 서버, 도메인, SSL 인증서(보안 자물쇠) 등 운영 환경 설정
   - 비용 효율적인 호스팅 방식 선택 (클라우드, 서버리스 등)

3. **문서화**
   - 사용자 가이드 (서비스 이용법)
   - 개발자 가이드 (코드 유지보수법)
   - API 문서 (외부 연동 방법)

4. **자가 복구 로직 설계**
   - 서비스 장애 시 자동 감지 및 복구
   - 헬스 체크(건강 검진) 시스템: 주기적으로 서비스가 정상인지 확인
   - 장애 발생 시 자동 알림 (이메일, 슬랙 등)

5. **백업 & 롤백**
   - 정기적 데이터 백업 설정
   - 문제 발생 시 이전 버전으로 되돌리기(롤백) 절차 수립

---

## 투입 시점
- 개발 중기 (배포 환경 준비)
- 개발 완료 후 (배포 실행)
- 운영 기간 (모니터링 및 유지보수)

## 협업 대상
- 총괄 감독 (배포 일정 보고)
- 리드 개발자 (배포 환경 설정 협의)
- 보안 QA (배포 환경 보안 점검)

---

## 배포 체크리스트

| 항목 | 확인 내용 | 상태 |
|------|-----------|------|
| 환경 변수 | 프로덕션용 설정 적용 완료 | ☐ |
| SSL 인증서 | HTTPS 보안 연결 설정 완료 | ☐ |
| 데이터 백업 | 배포 전 데이터 백업 완료 | ☐ |
| 롤백 절차 | 문제 시 되돌리기 절차 준비 완료 | ☐ |
| 모니터링 | 서비스 상태 감시 시스템 가동 | ☐ |
| 문서화 | 사용자/개발자 가이드 작성 완료 | ☐ |
| 알림 설정 | 장애 시 자동 알림 설정 완료 | ☐ |
