# .plan.md — Polymarket Reaper Bot v1.0

## 프로젝트명
Polymarket Reaper Bot v1.0 — Signal Marketplace 아키텍처

## 요구사항 (사용자 원문)
퀀트 수석 설계자로서 Polymarket 자동매매봇을 설계.
6가지 핵심 전략 + 파생 지표를 파괴적으로 발전시킨 아키텍처.
승률 52~55% 달성이 목표.

**핵심 전략 6개:**
1. 해결 기준 아비트라지 — 모호성 스코어링
2. 오라클 공포 프리미엄 — 오라클 불신 할인 감지
3. 군중 반대 지표 — Z-score 기반 과잉반응 감지
4. 연관 시장 비효율 — implied conditional 미스프라이싱
5. 유동성 진공 사냥 — 스프레드+깊이 비대칭 감지
6. 메타 봇 (Meta Brain) — 복합 시그널 수렴 탐지

**파생 지표 4개 (승인됨):**
7. Settlement Decay — 결제일 접근 시 시간가치 감소 수확
8. Event Cascade Lag — 연관 이벤트 간 가격 전파 지연 포착
9. Maker Rebate Harvesting — 메이커 리베이트 보장 구간 스나이핑
10. Whale Shadow — 고래 주문 흔적 추적 (WebSocket 실시간)

**아키텍처 (승인됨): Signal Marketplace**
- asyncio 이벤트 기반
- WebSocket 실시간 + REST 폴링 하이브리드
- Dual Pipeline: Sniper(속도) + Strategist(분석)
- Priority Signal Queue
- Meta Brain 수렴 탐지기

**리스크 파라미터:**
- Fractional Kelly 0.4 포지션 사이징
- 단일 시장 최대 15%
- 총 노출 최대 60%
- 일일 손실 8% 서킷브레이커
- Drawdown Throttle
- Correlation Guard

**기술:**
- Python, asyncio + aiohttp
- py-clob-client SDK (async wrapper)
- WebSocket for real-time data
- SQLite for trade log/signal log

## 전달 방식
소스코드 + 실행 스크립트 (start.sh / start.bat)

## AC (Acceptance Criteria)
- [ ] AC-1: Async API 클라이언트 — CLOB/Gamma/Data 3레이어, aiohttp 기반, L2 인증 HMAC, 지수 백오프, rate limit 관리. py-clob-client async wrapper.
- [ ] AC-2: WebSocket 매니저 — market 채널 구독, 실시간 오더북/체결 스트리밍, 자동 재연결, heartbeat 관리
- [ ] AC-3: Signal Queue + Event Bus — asyncio.PriorityQueue 기반 시그널 큐, 전략→큐→Meta Brain 파이프라인, 우선순위 라우팅
- [ ] AC-4: 전략1 Ambiguity Scoring (해결 기준 아비트라지) — 모호 키워드 TF-IDF 스코어링, 명확 소스 유무, NO 포지션 시그널
- [ ] AC-5: 전략2 Oracle Fear Premium — 분쟁 키워드/카테고리 감지, 5-10¢ 할인 탐지, 매수 시그널
- [ ] AC-6: 전략3 Contrarian Detector — 가격 Z-score, 주말 드리프트, 결제일 과열, 급등락 감지
- [ ] AC-7: 전략4 Correlated Markets — 태그 기반 군집화, implied conditional >1.5, Complete Set 아비트라지
- [ ] AC-8: 전략5 Liquidity Vacuum — 실시간 오더북 spread + depth 비대칭, GTC 리밋 시그널
- [ ] AC-9: 전략6 Meta Brain — 10개 전략 복합 스코어, 가중 평균 + 중첩 보너스, 수렴 탐지, 최종 TradeDecision 생성
- [ ] AC-10: 파생1 Settlement Decay — 결제일까지 잔여시간 기반 theta-like decay 계산, 시간가치 차익 시그널
- [ ] AC-11: 파생2 Event Cascade Lag — 연관 이벤트 가격 변동 전파 지연 탐지, lag window 내 차익 시그널
- [ ] AC-12: 파생3 Maker Rebate Harvesting — 메이커 리베이트 구간 계산, postOnly 리밋 시그널
- [ ] AC-13: 파생4 Whale Shadow — WebSocket 실시간 대량 주문 감지, 고래 방향 추종 시그널
- [ ] AC-14: Risk Sentinel 6층 방어 — Kelly Sizer(0.4), Single Market 15%, Total Exposure 60%, Circuit Breaker 8%/일, Drawdown Throttle, Correlation Guard
- [ ] AC-15: Dual Executor — Sniper(FOK/시장가 즉시체결) + Patient(GTC/postOnly), 시그널 urgency 기반 라우팅
- [ ] AC-16: 드라이런 모드 — 실거래 없이 시뮬레이션, 가상 P&L, 시그널/거래 로그 SQLite 저장
- [ ] AC-17: Trading Engine — asyncio 메인 루프, 전략 스케줄러(polling 주기 분배), WebSocket+REST 하이브리드, graceful shutdown
- [ ] AC-18: 설정 관리 — .env 기반 환경변수, config.py 통합 설정, 전략별 파라미터 오버라이드
- [ ] AC-19: 실행 환경 — start.sh/start.bat, .env.example, requirements.txt, 원스텝 설치→실행

- 유형: API/백엔드만 (3명) + 보안 (+1명) = 4명

- On-Demand: 보안(Opus) — 금융거래 + API키 + 개인키 관리 포함

## 기술 스택
- Python 3.10+ (asyncio native, match-case)
- py-clob-client: Polymarket 공식 Python SDK
- aiohttp: 비동기 HTTP + WebSocket 클라이언트
- asyncio: 이벤트 루프, PriorityQueue, Task 관리
- sqlite3 + aiosqlite: 비동기 DB (거래/시그널 로그)
- statistics: Z-score, 표준편차 (외부 의존 최소화)
