## 주요 설계 결정

### 1. 브랜드 컬러: Nugget Gold (#F5A623)

"Nugget"이라는 이름에서 금색 너겟을 연상시키는 따뜻한 골드를 Primary로 선정했습니다. AI 플랫폼들의 보라/초록/파랑과 명확히 구분되면서, CTA 버튼과 별표 아이콘에서 시선을 끌기 좋습니다.

### 2. 플랫폼 식별: 카드 좌측 4px 컬러 스트라이프

카드 좌측에 Claude(보라) / ChatGPT(초록) / Gemini(파랑) 색상 스트라이프를 배치하여, 카드 리스트를 스캔할 때 어떤 AI에서 온 대화인지 즉각 인지할 수 있게 했습니다.

### 3. Popup 고정 크기 400x580px

크롬 확장 팝업은 반응형이 불필요합니다. 대신 정보 밀도 최적화(카드 간격 8px, 패딩 12px)와 스크롤 전략(상단/하단 고정, 카드 리스트만 스크롤)에 집중했습니다.

### 4. 카드 접기/펼치기

작은 팝업 공간에서 많은 대화를 효율적으로 표시하기 위해, 기본 접힌 상태(질문 1줄 + 답변 2줄)에서 클릭으로 펼치는 방식을 채택했습니다.

### 5. Pro 유도: 부드러운 안내

AC-24의 "부드러운 안내" 원칙에 따라, 한도 도달 시 기능을 갑자기 차단하지 않고, `var(--color-pro)` 색상의 친근한 말풍선으로 안내하는 방식을 설계했습니다.

### 6. SVG 인라인 아이콘

Manifest V3의 CSP 제약과 번들러 미사용 환경을 고려하여, 외부 아이콘 라이브러리 없이 SVG 인라인 방식을 선택했습니다. `currentColor`로 부모 색상을 상속받아 유지보수가 쉽습니다.

### 7. 접근성 기본 탑재

키보드 탐색, aria 속성, reduced-motion 대응을 가이드에 포함시켜, 개발 단계에서 별도 접근성 작업 없이 자연스럽게 반영될 수 있도록 했습니다.

## 개발자 참고사항

1. **CSS 변수 우선:** 모든 색상/간격/크기를 CSS 변수로 정의했으므로, `:root`에 변수를 선언하면 전체 UI에 일관되게 적용됩니다.
2. **Vanilla JS + CSS:** 프레임워크 없이 구현하는 환경이므로, 컴포넌트 사양을 CSS 클래스 기반으로 상세히 기술했습니다.
3. **Shadow DOM:** 토스트 알림은 AI 사이트의 CSS와 충돌 방지를 위해 Shadow DOM 안에서 렌더링해야 합니다.
4. **prefers-reduced-motion:** 모든 애니메이션에 reduced-motion 대응이 필요합니다.
