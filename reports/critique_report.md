## 1차 CRITICAL 해결 여부 검토

### CRITICAL-1 (해결됨): AC-23 무료 한도 초과 시 삭제 → 아카이브 전환, AC-23a 백업 복원 정책 추가

- AC-23이 "삭제"에서 "archived:true 마킹(숨김 처리)"으로 변경되었다.
- AC-23a가 신설되어 "백업 복원 시 최신 500개만 활성, 나머지 자동 archived:true, 데이터 손실 없음"이 명시되었다.
- AC-17(백업/복원)과의 모순이 해소되었다. 적절한 해결.

### CRITICAL-2 (해결됨): 무료→Pro 전환 시 데이터 복구 방안

- AC-23에 "Pro 업그레이드 시 archived 해제되어 전체 열람 가능"이 명시되었다.
- 아카이브 방식 전환으로 데이터 영구 손실 리스크가 근본적으로 제거되었다. 적절한 해결.

### CRITICAL-3 (해결됨): AC-5 잡담 필터 다국어 기준

- AC-5가 이중 기준으로 개정되었다: CJK 문자 포함 시 15자 미만(글자 수), 라틴 문자만일 때 5단어 미만(단어 수).
- CJK 판별 기준도 유니코드 범위(U+3000~U+9FFF, U+AC00~U+D7AF)로 구체화되었다.
- 한국어 "파이썬 리스트 정렬 어떻게 해?" (14자)가 여전히 잡담 후보에 걸릴 수 있지만, 2단계(키워드 exact match)와 AND 조건(답변 200자 미만 동시 충족)으로 오분류 가능성이 상당히 낮아졌다. 적절한 해결.

### CRITICAL-4 (해결됨): Pro 상태 오프라인 정책 AC 공식화

- AC-24a가 신설되어 구체적인 정책이 AC로 공식화되었다:
  - 로컬 캐싱 7일 유효
  - 캐시 유효 기간 내 오프라인: Pro 유지
  - 캐시 만료 + 오프라인: Pro 기능 유지 + "구독 확인 필요" 배너
- Pre-mortem과 분리하여 정식 AC로 승격시킨 것은 적절하다. 해결됨.

### CRITICAL-5 (해결됨): AC-18 무료 사용자 백업 알림 정책

- AC-18이 무료/Pro를 분리하여 재정의되었다:
  - 무료: 400개(80%) 도달 시 "백업 권장" 뱃지 + 500개 도달 시 한도 안내
  - Pro: 500개 단위 마일스톤 알림
- 무료 사용자에게 한도 도달 전(80%)에 사전 경고를 주는 것은 좋은 설계다.
- 500개 도달 시 "새 대화는 오래된 것을 숨김 처리합니다" 안내가 아카이브 정책(AC-23)과 일관된다. 해결됨.

## 수정으로 인한 새로운 검토

### MINOR-9: Pre-mortem 3번과 AC-24a 캐시 유효 기간 불일치

Pre-mortem 3번은 여전히 "Pro 상태 로컬 캐싱 (24시간)"이라고 적혀 있으나, AC-24a는 "7일 유효"로 정의되었다. AC가 정식 기준이므로 개발자는 AC-24a를 따르겠지만, 문서 내 수치 불일치는 혼란을 줄 수 있다. Pre-mortem을 AC-24a와 일치시키는 것이 바람직하다.

### MINOR-10: AC-23 archived 엔트리의 스토리지 누적에 대한 상한선 부재

기존 "삭제" 정책에서 "아카이브(숨김)" 정책으로 전환한 것은 데이터 보존 측면에서 올바르나, 무료 사용자가 장기간 사용하면 archived 엔트리가 무한히 누적된다. chrome.storage.local에 unlimitedStorage 권한을 사용하더라도, 수천~수만 개의 archived 엔트리가 쌓이면 검색 성능과 백업 파일 크기에 영향을 줄 수 있다. 당장의 문제는 아니지만, 향후 archived 데이터 정리 정책(예: 1년 이상 된 archived는 별도 알림 후 삭제 가능 등)을 고려할 여지가 있다.

### MINOR-11: AC-24a "기능 차단하지 않음" 정책이 악용될 소지

AC-24a는 캐시 만료 + 오프라인 시에도 Pro 기능을 유지한다고 정의했다. 이는 사용자 친화적이나, 의도적으로 네트워크를 차단하여 구독 만료 후에도 Pro 기능을 계속 사용하는 악용이 이론적으로 가능하다. 다만 크롬 확장 프로그램 특성상 대부분의 사용이 온라인 환경에서 이루어지고, 핵심 기능(AI 대화 저장) 자체가 온라인을 전제하므로 실질적 악용 가능성은 낮다. 현재 정책이 사용자 경험 우선이라는 판단에서 합리적이다.
