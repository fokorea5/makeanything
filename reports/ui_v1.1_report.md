## 주요 설계 결정

### 1. Nugget Gold (#F5A623) 다크 배경 처리

다크 배경(`#1A1A2E`)에서 대비비 4.8:1로 WCAG AA를 통과하므로 **변경하지 않고 유지**했습니다.
`--nugget-primary-light`만 어두운 골드 톤(`#3D2E1A`)으로 반전하여 배경 하이라이트에 사용합니다.

### 2. 플랫폼 컬러 밝기 조정

- Claude: `#7C3AED` → `#9B6BFF` (+15%)
- ChatGPT: `#10A37F` → `#34D399` (+20%)
- Gemini: `#4285F4` → `#60A5FA` (+15%)

ChatGPT의 초록(`#10A37F`)이 다크 배경에서 대비가 가장 부족하여 가장 큰 밝기 보정을 적용했습니다.

### 3. data-theme 속성 방식

CSS 클래스(`class="dark"`) 대신 `data-theme="dark"` 속성을 채택했습니다.
이유: 클래스명 충돌 방지 + 의미론적 명확성 + CSS `[data-theme="dark"]` 셀렉터의 높은 특이성.

### 4. 테마 선택 UI: 세그먼트 버튼

드롭다운 대신 세그먼트 버튼(3-way toggle)을 선택했습니다.
3개 옵션이라 한 눈에 모두 보이고, 클릭 1번으로 전환이 가능합니다.
각 버튼에 아이콘(태양/달/모니터)을 배치하여 직관적 인지를 돕습니다.

### 5. 언어 UI: 네이티브 select 기반

커스텀 드롭다운 대신 네이티브 `<select>`에 스타일을 적용하는 방식을 채택했습니다.
접근성(키보드, 스크린리더)이 기본 보장되며, 옵션 수가 3개로 적어 복잡한 커스텀 UI가 불필요합니다.

### 6. 태그/칩 투명도: 10% → 15%

다크 배경에서 10% 투명도는 거의 보이지 않으므로, 15%로 상향하여 시인성을 확보했습니다.

## 개발자 참고사항

1. **CSS 변수 구조:** v1.0의 `:root` 변수를 `[data-theme="light"]`로 옮기고, `[data-theme="dark"]`를 추가합니다. `:root`에도 기본값(라이트)을 유지하여 data-theme 미설정 시에도 동작합니다.
2. **테마 초기화 순서:** 페이지 로드 시 FOUC(Flash of Unstyled Content) 방지를 위해, `<head>` 내 인라인이 아닌 별도 JS 파일에서 `document_start` 시점에 `data-theme`을 설정합니다. MV3 CSP 때문에 인라인 스크립트는 사용 불가합니다.
3. **Shadow DOM 토스트:** Content Script 토스트는 Shadow DOM 내부이므로, 전역 CSS 변수를 Shadow Root에 별도로 주입해야 합니다.
4. **검색 하이라이트:** 다크 모드에서 노란색(`#FEF08A`)은 다크 텍스트에서 읽기 어려우므로, 어두운 골드(`#78500A`)로 교체합니다.
5. **transition 성능:** `transition: all` 대신 필요한 속성만 명시합니다 (background-color, border-color, color, box-shadow).
