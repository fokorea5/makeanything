[필수 질문 체크리스트]
사용자에게 다음을 확인하세요. 이미 명시된 항목은 건너뜁니다.

1. 핵심 기능은? — "가장 중요한 기능 1~3개가 뭔가요?"
2. 어디서 쓸 건가요? — 웹 / 데스크톱 / 모바일 / 스크립트
3. 외부 의존성이 있나요? — 외부 API, 서드파티 서비스, SDK
   YES → "해당 API의 인증 방식, 접근 가능 여부를 알고 계신가요?"
         모르면 → 오라클 소환하여 API 실현 가능성 조사.
4. 기술 선호? — 언어/프레임워크. "알아서"도 OK
5. 완성물을 어떻게 받으실래요? — 소스코드 / 더블클릭실행 / zip / 도커

[조사 필요 시]
오라클 소환 → 기술 조사 (API, 제약, 실현 가능성)

[구체화 완료 후]
답변 → .plan.md → PLAN 진입
